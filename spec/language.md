# Visual language

The design language is a **decoder of declared metadata**, not a second IR.

Formal translation (LaTeX + machine table): [`translation.md`](translation.md), [`encodings/ir-map.json`](../encodings/ir-map.json).

- Cores: provider hue, model geometry, effort orbits, topology envelope, operating-mode rune, runtime cadence.
- Silhouettes: `encodings/topology-graphs.json`, shown in `language/` *after* the calculus.
- Compilation: \(\tau\) in `encodings/ir-map.json`. Status `not-inferred` (swarm, unlabeled hybrid) still fails closed.

zerOS HomeForge `PAGE-ZEROS-AGENT-CORES` is a consumer of this catalog. Do not let that page grow a parallel id set.

See `encodings/README.md`.
